## Research focus: MADAALA

I am the **proposed Principal Investigator for MADAALA**, an AAU-led research proposal on human-grounded evaluation of multilingual AI in **Amharic and Afaan Oromo**, with English as a comparison condition.

The project asks whether matched user intents receive comparably accurate, useful, contextually appropriate and safe AI assistance across languages. The proposed study combines locally authored scenarios, native-speaker evaluation, language-parity analysis and validation of automated judges against human ratings.

My proposed responsibilities include technical infrastructure, student mentorship and in-country coordination. The project builds on my teaching in distributed systems, software quality, web programming and requirements analysis, alongside experience developing software for Ethiopian institutional settings.

The [MADAALA repository](https://github.com/wondimagegn/MADAALA) contains an executable Python prototype with Amazon Bedrock and offline mock workflows, dataset validation, blinded evaluation exports and analysis tools. The planned benchmark and full evaluation study remain in development; the completed technical pilot establishes pipeline feasibility rather than validated language-parity findings.

Read the [research methodology](https://github.com/wondimagegn/MADAALA/blob/main/docs/methodology.md) and [implementation roadmap](https://github.com/wondimagegn/MADAALA/blob/main/docs/madaala-roadmap.md).
